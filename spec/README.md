# Kontana specifications

The canonical references for the implemented application are:

1. [APP_SPEC.md](APP_SPEC.md) — product promise, navigation, wallets, payments, Budget mode, full local history, backup/import, settings, offline behavior.
2. [DESIGN_SPEC.md](DESIGN_SPEC.md) — approved visual system, both themes, bilingual website, responsive app, accessibility, and source-file map.
3. [OPEN_CORE_SPEC.md](OPEN_CORE_SPEC.md) — MPL-2.0 boundaries, free-core guarantee and exploratory paid services.
4. [RELEASE_VERIFICATION.md](RELEASE_VERIFICATION.md) — checks performed for this implementation.
5. [Editable design](../design/new-kontana-design.pen) — desktop/mobile design examples.

Detailed behavior and algorithms: [Cash](CASH_ON_HAND.md), [Payments](NEW_PAYMENT.md), [Transactions](TRANSACTIONS.md), [Settings](SETTINGS.md), [Data model](DATA_MODEL.md), [Algorithms](ALGORITHMS.md), [Privacy/security](PRIVACY_SECURITY.md), [Technical decisions](TECH_DECISIONS.md), and [Acceptance tests](ACCEPTANCE_TESTS.md).

The numbered `00`–`60` documents retain the Budget feature planning/workflow detail. When older planning or screen instructions differ from the current release, APP_SPEC and DESIGN_SPEC take precedence. `design-terminal.md` is a superseded pointer, not a second design system.
