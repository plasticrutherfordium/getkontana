# Licensing and the free-core model

## Scope

MPL-2.0 covers first-party application code, Hugo templates, styles, helper modules, tests, scripts, configuration, and the accompanying first-party documentation/design source, except where a file or the notices below state another licence. Source headers use the SPDX identifier; sidecar `.license` files or `REUSE.toml` attach it to formats that cannot contain comments. MPL is also used for the documentation/design material created for this application for consistency; this is not a claim to relicense third-party materials.

Third-party fonts, the Terminal theme, bundled PDF code and its dependencies retain their original licences. The original Kontana brand artwork and pre-existing standalone icon assets retain their existing MIT copyright permissions. See [NOTICE](NOTICE), [LICENSES/MIT-legacy.txt](LICENSES/MIT-legacy.txt), and the licence notices shipped alongside the relevant assets. No third-party binary, font, logo or theme is relabelled MPL by this change.

This licence covers project source/materials, not a user’s wallet records, transaction history or camera images. Publishing the software does not publish user data.

## What stays free

The core app stays free, forever: wallets, precise cash payments, Budget mode, complete local transaction/check-in history, JSON backups/import and PDF reports. No account or subscription is required for the core. Core operation, manual entry, full history, export and recovery must remain useful without any paid feature.

Optional paid extras may be offered separately. MCP connections, managed AI services and camera-assisted denomination counting are **exploratory future features**, not shipped Premium functionality. There is no active Premium plan, checkout, subscription or promised release date in this repository.

## Core and optional components

MPL uses file-level copyleft. Distributed modifications to covered source files remain under MPL-2.0. New separate files containing no MPL-covered code can have other terms, including proprietary terms, while a larger combined product still meets the MPL obligations for the core. Moving or copying covered code into a new file does not remove those obligations. See [Mozilla's FAQ](https://www.mozilla.org/en-US/MPL/2.0/FAQ/), especially questions 9–12 and 16–17.

Future paid code must have its own explicit licence notice and live outside the core's covered files. Paid hosted services must have their own terms and privacy disclosure before launch. No proprietary exception is applied to the current core source. Open source permits commercial use and competition; MPL is not a prohibition on charging, rehosting or forking.
